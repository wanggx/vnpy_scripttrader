# K线图表形态识别开源库整理

本文整理的是图表结构类识别工具，重点是三角形、趋势通道、支撑压力、趋势线、头肩、双顶双底等形态，不是 TA-Lib 中的单根或多根蜡烛图形态。

## 推荐库

### pytrendline

GitHub: <https://github.com/ednunezg/pytrendline>

专门用于检测支撑线和压力线的 Python 库。它基于 OHLC 数据，从高点、低点、收盘价中寻找可能形成趋势线的点。

适合：支撑线、压力线、趋势线扫描，以及三角形、通道等形态的底层组件。

### trendln

GitHub: <https://github.com/GregoryMorse/trendln>

用于计算支撑线和压力线的 Python 库，可以查找局部极值，并基于这些极值拟合趋势线。

适合：局部高低点识别、趋势线拟合、支撑压力计算，以及构造通道、三角形、突破检测逻辑。

### ta-patterns

PyPI: <https://pypi.org/project/ta-patterns/>

较新的 Python 库，主打向量化技术分析形态识别，包含 K线形态和图表形态。

适合：批量扫描多种图表形态，快速验证形态识别想法。

注意：项目较新，建议先用历史样本和人工标注图做验证，不建议直接用于实盘。

### price-action-lib

PyPI: <https://pypi.org/project/price-action-lib/>

偏价格行为分析，覆盖支撑压力、趋势结构、chart patterns 等内容。

适合：支撑压力、三角形、楔形、旗形、头肩、双顶双底等结构识别。

### PatternPy

GitHub: <https://github.com/keithorange/PatternPy>

Python 图表形态识别项目，包含头肩、顶部/底部、支撑压力等功能。

适合：学习图表形态识别实现思路，或作为自定义规则的参考代码。

## 推荐落地路线

对于 vn.py 或 Python 量化项目，建议不要一开始追求“万能图表形态识别库”。更稳的路线是先构建自己的结构识别流程。

### 第一步：识别波峰波谷

常用方法：

- ZigZag
- Fractal 分形
- rolling window 局部最大值/最小值
- ATR 或百分比阈值过滤噪音

目标是从原始 K 线中提取关键 pivot 点。

### 第二步：计算支撑压力和趋势线

可以使用：

- `trendln`
- `pytrendline`

输出结果包括：

- 水平支撑位
- 水平压力位
- 上升趋势线
- 下降趋势线
- 可能的价格通道边界

### 第三步：封装图表形态规则

#### 上升三角形

- 压力线近似水平
- 低点逐步抬高
- 价格波动区间逐渐收敛
- 向上突破压力线时触发信号

#### 下降三角形

- 支撑线近似水平
- 高点逐步降低
- 价格波动区间逐渐收敛
- 向下跌破支撑线时触发信号

#### 对称三角形

- 高点逐步降低
- 低点逐步抬高
- 上下边界线逐渐收敛
- 突破方向决定后续信号方向

#### 上升/下降通道

- 两条趋势线斜率接近
- 上下边界距离相对稳定
- 价格多次触碰上下轨
- 突破通道边界时触发趋势变化信号

#### 支撑压力突破

- 收盘价有效越过支撑/压力线
- 突破幅度超过 ATR 或固定百分比阈值
- 可结合成交量放大过滤假突破
- 可要求连续 N 根 K 线站上/跌破确认

## 实盘前需要验证的重点

- 是否存在未来函数
- pivot 点是否只使用当前时间之前的数据
- 趋势线是否会随新 K 线大幅漂移
- 对不同周期是否稳定，例如 5分钟、30分钟、日线
- 对不同品种是否稳定，例如股票、期货、ETF
- 假突破过滤是否有效
- 信号出现频率是否过高或过低
- 回测中是否包含手续费、滑点、涨跌停、停牌等约束

## 个人建议

如果目标是做可控、可回测、可调参的形态识别，优先组合：

1. `ZigZag / Fractal / local extrema` 提取关键高低点
2. `trendln` 或 `pytrendline` 计算趋势线和支撑压力
3. 自己封装三角形、通道、突破规则
4. 用历史数据和人工标注样本验证识别质量

图表形态的主观性很强，库只能提供候选结构。真正适合交易系统的部分，通常需要自己把规则参数化，并通过回测和样本复核不断收敛。
